# Seunghyun

Software architect based in South Korea.

I spend most of my time building product code, developer tools, and small systems around AI agents, market data, and frontend workflows.

I like software that is easy to inspect: clear inputs, clear outputs, tests that mean something, and docs that stay close to the code.

## Public Work

[PatchDrill](https://github.com/seungdori/patchdrill)

A deterministic proof layer for code review. It reads a git diff and points out the verification that should exist before a patch is merged.

[Tickscope MCP](https://github.com/seungdori/tickscope-mcp)

An MCP server for live crypto market data, indicators, and chart structure. Built so agents can ask for market context without scraping around for it.

[Web Stylebook](https://github.com/seungdori/web-stylebook)

A collection of web style references and prompt workflows for frontend work. Mostly a practical reference shelf for turning a visual direction into code.

## Usually Working With

TypeScript, Python, React, Node.js, PostgreSQL, Docker, GitHub Actions, and whatever the project actually needs.

## Notes

I care more about whether a system can be checked and maintained than whether it looks clever at first glance.
