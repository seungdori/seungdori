## Focus

I build systems where AI agents and developers need reliable tools, fresh data, and reviewable proof.

- Deterministic developer tools for safer AI-assisted code review.
- MCP and market-data infrastructure for agents that need live external context.
- Frontend style systems that turn design direction into repeatable implementation workflows.
- Full-stack products shaped around clear source-of-truth boundaries, verification, and release discipline.

## How I Work

- Build the proof path first: tests, CI, release checks, and source-of-truth docs.
- Prefer local-first systems with deterministic behavior and inspectable output.
- Turn messy workflows into tools that other developers can run, audit, and extend.
